# Customer Churn Analytics Dashboard

An interactive **Customer Churn Analytics dashboard** built with Microsoft Power BI to analyze customer churn, retention patterns, customer demographics, and key business metrics.

## 📊 Project Overview

This project analyzes a dataset containing **1,000 customer records** to identify patterns and factors associated with customer churn.

The dashboard provides an interactive view of customer behavior and allows users to explore churn across different customer segments.

## 🎯 Dashboard Pages

### 1. Executive Summary

The Executive Summary provides a high-level overview of customer churn and retention, including:

* Total Customers
* Churned Customers
* Retained Customers
* Churn Rate
* Customer demographics
* Overall churn patterns
* Key customer segments

### 2. Customer Deep Dive

The Customer Deep Dive page provides a more detailed analysis of customer-level behavior and churn patterns.

It allows users to explore:

* Customer characteristics
* Churn patterns across different segments
* Demographic factors
* Customer-related metrics
* Detailed customer analysis using interactive filters

## 📈 Dashboard Features

* Interactive KPI cards
* Churn and retention analysis
* Customer segmentation
* Demographic analysis
* Interactive charts and visualizations
* Slicers and filters
* Detailed customer-level analysis

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Microsoft Excel**

## 🔄 Data Preparation

The dataset was prepared using Power Query before creating the dashboard.

The data preparation process included:

* Cleaning the dataset
* Checking and correcting data types
* Handling inconsistent values
* Transforming columns for analysis
* Preparing the data for visualization

## 💡 Key Insights

The dashboard can be used to identify:

* Overall customer churn and retention levels
* Customer segments with higher churn
* Demographic differences between churned and retained customers
* Patterns associated with customer churn
* Areas for further customer retention analysis
